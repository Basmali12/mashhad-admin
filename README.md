# مشهد أدمن

لوحة عربية RTL منفصلة لإدارة محافظ نقاط مشهد. المستودع: https://github.com/Basmali12/mashhad-admin . نُشرت واجهة الأدمن بموافقة المالك على GitHub Pages: https://basmali12.github.io/mashhad-admin/ . هذا النشر يخص لوحة الأدمن فقط.

## التشغيل

`npm install` ثم انسخ `.env.example` إلى `.env.local` واضبط عنوان Convex Development ومفتاح Clerk العام لنفس مشروع مشهد. لا تحتاج الواجهة مفتاح نشر أو مفتاح Worker سريًا.

`npm run dev` يفتح http://127.0.0.1:43132/ . الفحوص: `npm run typecheck` و`npm run lint` و`npm run build`.

قاعدة البيانات مشتركة مع مشهد، ووظائف الخادم والمخطط واختباراتها موجودة في المشروع الحالي `../ad-studio/convex/wallets.ts` و`schema.ts` و`wallets.test.ts`. لا تنشئ قاعدة ثانية ولا تنشر الإنتاج لتشغيل هذه اللوحة. `OWNER_SUBJECT` و`CLERK_JWT_ISSUER_DOMAIN` يُضبطان في إعدادات Convex؛ لا يمنح الكود الأمامي دور الأدمن.

## الاستخدام

يسجّل المستخدم في مشهد ويفتح «محفظة النقاط» لإنشاء معرّف MS ثابت برصيد صفر وصلاحيات معطلة. المالك يبحث بالمعرّف أو الاسم، ويفتح المحفظة لإضافة النقاط أو تصحيح الرصيد مع سبب محفوظ، وتحديد الموديلات وحد المقاطع. لا تُحذف الحركات ولا يسمح برصيد سالب. لكل حركة مفتاح ثابت يُحفظ في جلسة المتصفح حتى تأكيد الحفظ؛ إعادة المحاولة تستخدم المفتاح نفسه.

في «الصلاحيات والتسعير»، اعتمد الكلفة المرصودة من خيارات Worker خلال آخر ساعة. السعر لكل موديل ودقة ومدة مقطع؛ تعدد المقاطع يضاعف السعر. اختلاف سعر المقاسات يمنع الاستيراد، ولا تُستبدل الأسعار المعدلة يدويًا تلقائيًا. النقاط داخلية وليست رصيد Google Flow ولا إثبات استهلاك فعلي.

التبويبات: الزبائن، المحافظ، سجل الحركات، الصلاحيات والتسعير. تعرض اللوحة أحدث 200 محفظة وأحدث 100 حركة، ويعرض المستخدم آخر 100 حركة لمحفظته فقط. واجهة العملاء للتوليد والخصم التلقائي لم تُربطا بعد؛ بيانات الطلبات والفيديوهات الشخصية ومسار التوليد الحالي ما زالت محمية للمالك.

## التحقق المحلي

نجحت TypeScript وlint وbuild في التطبيقين و56 اختبارًا في مشهد، منها ستة اختبارات للمحفظة: المصادقة، عزل الحسابات، تكرار الحركات، الأرقام والرصيد، صلاحيات التسعير، والاستيراد الحديث مع حفظ الأسعار اليدوية. اختُبر فعليًا تسجيل محفظة المالك وإضافة 100 ثم خصمها لإرجاع الرصيد لصفر مع ظهور التغيير المباشر والسجل. اعتُمدت أربعة أسعار حقيقية مرصودة دون توليد جديد. لم يُختبر تسجيل حساب ثانٍ حيًا؛ عزل الحسابات اختُبر بوظائف الخادم بهويات اختبار.
